📦 Cách tích hợp

1️⃣ Cơ bản (Localhost)

<!-- Thêm vào trước thẻ </body> --> <script src="http://localhost:5173/widget.js"></script>

2️⃣ Production (Tùy chỉnh API)

<!-- Thêm vào trước thẻ </body> --> <script src="https://yourdomain.com/widget.js" data-api-url="https://chatbotbe.a2alab.vn" data-ws-url="wss://chatbotbe.a2alab.vn" ></script>
💡 Lưu ý:
• data-api-url: URL của backend API (HTTP/HTTPS)
• data-ws-url: URL của WebSocket server (WS/WSS)
• Widget sẽ tự động lưu sessionId vào localStorage
• url_channel sẽ tự động được lưu là URL của trang hiện tại
